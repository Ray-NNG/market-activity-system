### 新建活动功能诊断与修复（2026-03-21）
- 用户反馈点击"新建活动"按钮无反应
- 错误: `Uncaught ReferenceError: Cannot access 'budgetItemCount' before initialization`
- 根本原因: `let` 声明存在暂时性死区(TDZ)，函数调用时变量尚未初始化
- 修复方案: 将 `let budgetItemCount`、`let activities`、`let fileStore`、`let currentBinVersion`、`let calYear/calMonth` 全部改为 `var`
- 添加 `<meta http-equiv="Cache-Control" content="no-cache">` 强制浏览器刷新缓存
- 已推送到 GitHub Pages

### 点击无反应 bug 修复（2026-03-23）
- 用户反馈活动流程概览点击无反应，前期策划查看详情/转为执行中无反应
- 根本原因: 活动 id 存储为字符串（`String(Date.now())`），但 onclick 模板插值时裸写 `${a.id}` 变成数字传入函数，`find(x=>x.id===id)` 严格比较 `"123" !== 123` 导致找不到活动，函数静默失败
- 修复范围:
  1. 所有 onclick 里的 `${a.id}` 加引号 → `'${a.id}'`（18 处）
  2. openDetail / advanceActivity / doDeleteActivity / saveReview / aiGenerateReview / toggleTask / updateKpi 内部比较改用 `String(x.id)===String(id)`
  3. 加 `if(index===-1) return` 防护
