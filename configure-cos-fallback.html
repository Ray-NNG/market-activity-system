💾 方案二：使用离线模式（无需 COS SDK）

如果无法访问任何 CDN，可以使用 HTTP API 直接与 COS 交互

步骤：

这个方案不需要加载 COS SDK，直接使用 fetch API 调用腾讯云 COS 接口：

const adapter = {
    getData: async function() {
        // 使用 REST API 直接调用 COS
        const response = await fetch('https://nnqgcvte2026-1414699807.cos.ap-guangzhou.myqcloud.com/data.json');
        return response.json();
    },
    saveData: async function(data) {
        // 使用 REST API 上传数据
        const response = await fetch('https://nnqgcvte2026-1414699807.cos.ap-guangzhou.myqcloud.com/data.json', {
            method: 'PUT',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(data)
        });
        return response;
    }
};

✅ 方案三：手动配置适配器

最简单直接的方案：手动配置适配器，跳过 SDK 加载问题

步骤：

点击下方按钮，直接配置适配器（不依赖 COS SDK）：

// 在浏览器控制台执行以下代码：
window.MarketActivityCOS = {
    adapter: {
        getData: async () => {
            const localData = localStorage.getItem('market_activities_data_frontend');
            return localData ? JSON.parse(localData) : { activities: [], files: {} };
        },
        saveData: async (data) => {
            localStorage.setItem('market_activities_data_frontend', JSON.stringify(data));
            console.log('✅ 数据已保存到本地（COS SDK 加载失败，使用本地备份）');
            return true;
        }
    }
};
